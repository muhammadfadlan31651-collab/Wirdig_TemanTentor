# TemanTutor - Platform Penghubung Tentor & Murid

TemanTutor adalah platform penghubung antara murid dan tentor les privat dengan sistem token kredit. Murid memposting kebutuhan bimbingan belajar di Bursa Job, dan tentor dapat langsung melamar tawaran yang sesuai secara efisien tanpa perantara dan 0% potongan komisi sesi mengajar.

## Identitas Brand & Warna (Sesuai Logo)
- **Brand Name**: TemanTutor
- **Warna Utama**:
  - Deep Navy Slate: `#353956`
  - Periwinkle / Lavender Accent: `#8B95C9`
  - Pure White: `#FFFFFF`
  - Emerald Accent: `#059669`

## Aturan Bisnis & Fitur Unggulan
1. **Harga Ditentukan oleh Murid**: Murid memasang tawaran fee per sesi yang diinginkan saat posting kebutuhan di bursa job.
2. **Bursa Kebutuhan Tentor (`/job-board`)**: Pusat lowongan mengajar aktif di mana tentor dapat langsung menawarkan diri.
3. **Sistem Token Kredit**: 1 Token untuk memposting kebutuhan les, 1 Token untuk tentor melamar pekerjaan.
4. **0% Potongan Komisi**: 100% honor mengajar menjadi hak tentor tanpa potongan biaya platform.
5. **Kontak Langsung**: Terhubung via WhatsApp dan chat interaktif setelah tentor mengajukan penawaran.
6. **Perlindungan Murid Minor**: Pendampingan kontak orang tua/wali khusus untuk jenjang SD & SMP.

## Cara Menjalankan
```bash
npm install
npm run dev
```
